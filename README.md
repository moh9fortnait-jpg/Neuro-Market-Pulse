# 07. Neuro-Market Pulse

## Concept
A financial simulation engine that models stock price volatility using stochastic logic. This project focuses on state management (tracking balance, shares, and prices) across multiple iterations.

## Innovation
The project uses the **`random` library** to implement a "Dynamic Market Logic." It forces the user to apply risk management and strategic decision-making, simulating a real-world economic environment within a simple console application.

## How to Run
1. Run: `python main.py`
2. You start with $1000.
3. Observe the daily price changes and decide whether to Buy, Sell, or Hold.
4. Try to increase your Net Worth by the end of Day 5.

*Part of the NeuroVerse: Origin series.*
